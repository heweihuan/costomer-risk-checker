
客户背景批量核查工具（课程项目）

本项目为课程实践项目，用于模拟客户背景核查流程。项目读取虚拟客户名单，批量查询企业公开工商信息，并结合规则与大模型接口输出风险等级，最终导出 Excel 报告。

功能特点

- 读取 Excel 客户名单，支持批量查询
- 汇总登记状态、注册资本、参保人数、法定代表人、成立时间、经营异常等信息
- 支持规则判断与大模型风险总结两种模式
- 未配置接口密钥时，可使用虚拟演示数据直接运行
- 自动导出核查结果 Excel
- 接口密钥通过环境变量配置，不写入代码

技术栈

Python、pandas、requests、openai、Excel 文件处理

运行方式

1. 安装依赖：

pip install pandas requests openpyxl

2. 可选配置环境变量：

export QCC_KEY=你的企业数据接口密钥
export OPENAI_API_KEY=你的大模型密钥

如果不配置密钥，程序会使用虚拟演示数据运行，适合课程学习和演示。

3. 运行程序：

Ai自动查询.py

也可以指定自己的客户名单文件：

Ai自动查询.py 虚拟客户名单.xlsx

程序会生成 客户背景核查结果.xlsx。

输出字段

公司名、登记状态、注册资本、参保人数、法定代表人、成立时间、经营异常、风险总结。

注意事项

- 本项目仅用于课程学习，客户名单均为虚拟数据
- 不采集个人隐私信息
- 不爬取需要登录或受保护的数据
